# VENTURA — Unhas em Gel

Projeto pronto para publicar no GitHub Pages e abrir no computador, celular e tablet Samsung com Android.

## Publicar no GitHub
1. Crie um repositório no GitHub (por exemplo, `ventura-unhas-em-gel`).
2. Extraia este ZIP.
3. Envie **todos os arquivos e pastas** para a raiz do repositório, mantendo `index.html` na raiz.
4. No GitHub, entre em **Settings → Pages**. Em *Build and deployment*, escolha **Deploy from a branch**, selecione `main` e `/ (root)` e salve.
5. Aguarde a publicação e abra o endereço `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`.

## Instalar no tablet Samsung / Android
1. Abra o endereço publicado no **Chrome** do tablet, com internet.
2. Abra o menu ⋮ do Chrome e escolha **Instalar app** ou **Adicionar à tela inicial**.
3. Confirme. O ícone Ventura ficará disponível como um app.

## Importante sobre os dados
Os lançamentos ficam salvos no armazenamento local do navegador/dispositivo. Isso significa que os registros do computador não aparecem automaticamente no tablet. Use **Configurações → Backup dos dados** para exportar no aparelho de origem e importar no outro. Guarde cópias do backup.

A tela de abertura fecha automaticamente após 3 segundos e a tela inicial mostra “Bem-vinda, Steffanny”.
